# YouType - Listen & Type English Practice

ভিডিওতে দেখানো ইন্টারঅ্যাক্টিভ **"Listen and write what you hear"** টাইপিং ও লার্নিং প্ল্যাটফর্ম।

## 🌟 প্রধান ফিচারসমূহ (Features):

1. **Audio Synthesis & Natural Speech (TTS):**
   - প্রতি ধাপে ইংরেজি বাক্য স্বয়ংক্রিয়ভাবে প্রোনাউন্স করে (Web Speech API)।
   - পুনরায় শোনার বাটন এবং কীবোর্ড শর্টকাট (`Tab` বা `Space`)।
   - স্পিড কন্ট্রোল: স্বাভাবিক (1.0x) এবং ধীরগতি (0.75x)।

2. **Word Tokens & Grammar Chips:**
   - বাক্যের প্রতিটি শব্দ আলাদা ব্যাজ/টোকেন আকারে প্রদর্শিত হয় (যেমন: *Pronoun*, *Verb*, *Article*, *Noun*, *Adverb*)।
   - বর্তমানে কোন শব্দ টাইপ হচ্ছে তার রিয়েল-টাইম হাইলাইট।
   - "Hard Mode" টগল করে শব্দগুলো লুকিয়ে শুধু অডিও শুনে টাইপ করার সুবিধা।

3. **Real-time Tactile Typing:**
   - কীবোর্ডে টাইপ করার সাথে সাথে শব্দের নিচে সুন্দর আন্ডারলাইন ও লেটার ফিল-আপ।
   - মেকানিকাল কীবোর্ড টাইপিং সাউন্ড এফেক্ট।
   - ভুল চাপলে লাল ভাইব্রেশন ও এরর টোন।
   - সঠিক বাক্য টাইপ সম্পন্ন হলে ভিক্টোরি চাইম এবং স্বয়ংক্রিয়ভাবে পরবর্তী বাক্যে চলে যাওয়া।

4. **Lesson Complete Screen (ভিডিওর মতো হুবহু):**
   - কনফেটি অ্যানিমেশন।
   - লেসন ১ কমপ্লিট কার্ড (হ্যালো থ্রিডি ব্লক গ্রাফিক্সসহ)।
   - অ্যাকুরেসি (Accuracy %), টাইম টেকেন (Time), টাইপিং স্পিড (WPM)।
   - পরবর্তী লেসনে যাওয়ার বাটন ("Continue to next lesson")।

5. **Multiple Lessons & Custom Mode:**
   - **Lesson 1:** The first lesson for beginners (ভিডিওর হুবহু বাক্যসমূহ)
   - **Lesson 2:** Talk about your family and day
   - **Lesson 3:** Study, Work and Skills
   - **Custom Practice:** যেকোনো ইংরেজি প্যারাগ্রাফ বা বাক্য পেস্ট করে তাৎক্ষণিক প্র্যাকটিস করার সুবিধা!

## 🚀 রান করার নিয়ম (How to Run):

প্রজেক্ট ডিরেক্টরিতে টার্মিনাল খুলে কমান্ড দিন:

```bash
# ডেভেলপমেন্ট সার্ভার চালু করতে:
npm run dev

# প্রোডাকশন বিল্ড তৈরি করতে:
npm run build
```

ব্রাউজারে ওপেন করুন: `http://localhost:3000`
